# 档案侦探 · 笼中密码 v1.4.0

一款**教学型杀手数独（Killer Sudoku）**游戏，同时支持**浏览器**、**抖音小程序**与独立APK运行。以侦探叙事为载体，从 4×4 入门到 9×9 精通，循序渐进地教授杀手数独解题技巧；高级技巧章节配备**可视化交互教程**；每章末设有**「幽灵迷雾」对战Boss战**，玩家与AI在同一张棋盘上竞速填数。

### v1.4.0 (2026-07-06)

**🆕 推理与提示联动系统（RAHS）**

9个模块组成的智能提示系统，实时监控玩家推理状态，角色主动说话给提示：

| 模块 | 功能 |
|:----:|------|
| reasoning-monitor | L1-L4 推理状态监控（频率/空间/准确率/沉默） |
| eureka-detector | Eureka 时刻检测（沉默+连锁坍塌+盲解 三重锁） |

| hint-director | 提示引导器（影响力引擎选目标格+风格匹配） |
| note-playback | 笔记回放系统（录制/回放/统计） |

## 特色系统

### 🧠 推理与提示联动系统（RAHS）— v1.4 新增

**四重推理监控：**
- L1 基础层：笔记频率（最近60秒写了多少笔记）
- L2 空间层：空间集中度（笔记集中在哪些区域）
- L3 表现层：准确率 + 错误率
- L4 行为层：沉默时长 + 笔记-填数间隔

**Eureka 检测：**
三重条件同时满足才触发：
1. 沉默 ≥ 8秒（深度思考）
2. 连锁坍塌 ≥ 3格（填一个数带动3个以上）
3. 最近30秒无提示（盲解状态）

**动态阈值：**
- Eureka 状态 → 立即触发（0秒）
- 高频高准 → 延后30秒（人家在认真想）
- 高频低准 → 强制30秒触发（防涂鸦）
- 低笔记 → 提前20秒（卡壳了）
- 高错误 → 提前15秒（需要帮助）

**角色说错机制：**
| 角色 | 说错概率 | 上限/局 | 新手保护 |
|:----:|:--------:|:-------:|:--------:|
| 阿岩 | 15% | 3次 | 前5次 ×0.3 |
| 守笼人 | 0% | 0 | - |
| 设局人 | 5% | 2次 | - |

### 🎯 三阶段教学框架

```
开局（opening）→ 破局（breakthrough）→ 收官（finishing）→ 通关
```

- **开局**：用基础技巧（裸单/隐单/45法则）填入明显格子，舒缓BGM
- **破局**：基础技巧卡壳，触发高级技巧教学，BGM切换紧张风格
- **收官**：突破后连锁反应完成剩余格子，明快收尾BGM

### 💡 三层提示系统

| 点击次数 | 提示内容 | 视觉效果 |
|:--------:|----------|----------|
| 第1次 | 高亮一个可填的格子 | 🔸 脉冲光晕动画 |
| 第2次 | 在该高亮格上显示正确数字（半透明） | 🔹 数字淡入动画 |
| 第3次 | 自动填入该数字 | ✨ 填入动画 |

### 🎭 剧情演出系统

- 8个可交互角色（守笼人、阿岩、设局人等），各有立绘、表情和配音
- "逆转裁判"级演出（砸入动画、情绪推近、异议指示器）
- 每章开场/收尾剧情，通关解锁徽章

### 📝 笔记回放 — v1.4 新增

- 自动记录所有笔记操作轨迹
- 回放面板显示：笔记数 / 填数 / 用时
- 支持播放 / 停止 / 进度显示

### 🧮 45法则账本

- 实时显示每个笼子的可能组合
- 支持点击笼子查看详细组合
- Innie / Outie 自动计算

## 题库系统

### 数据文件结构

```
game-src/data/puzzles/
├── v6/                          # V6 主题库（2649道纯杀手）
│   ├── killer-pure-1star.json   # 1星 421道
│   ├── killer-pure-2star.json   # 2星 646道
│   ├── killer-pure-3star.json   # 3星 400道
│   ├── killer-pure-4star.json   # 4星 937道
│   ├── killer-pure-5star.json   # 5星 245道
│   └── killer-stuck-endgame.json # 卡壳残局 69道
├── by-min-tech/                 # 按最低必要技巧分类（v1.4新增）
│   ├── index.json               # 轻量索引
│   ├── nakedSingle.json         # 裸单 145道
│   ├── cageUnique.json          # 笼子唯一组合 152道
│   ├── hiddenSingle.json        # 隐单 421道
│   ├── rule45.json              # 45法则 1753道
│   └── nakedPair.json           # 显性数对 178道
├── seeds/                       # 种子题库（305道）
│   └── all-killer-seeds.json
└── techniques/                  # 技巧示范题
```

### 题目标题字段（V6）

| 字段 | 说明 |
|------|------|
| id | 唯一ID |
| difficulty | 星级（1星~5星） |
| difficultyScore | 难度分（0-1000） |
| maxTechLevel | 最高技巧等级（1-9）= 最低必要技巧 |
| techCount | 各技巧使用次数 |
| totalSteps | 总填数步数 |
| nonTrivialRatio | 非裸单比例 |
| boardData / cages / solution | 棋盘 / 笼子 / 正解 |

### Pipeline V6 生成流程

```
种子题库 → 唯一解验证 → 技巧评级 → 分类 → 变体生成 → 残局生成 → 输出
```

工具位于 `crawlers/` 目录：
- `pipeline-v6.js` — 主流水线
- `tech-rater-v2.js` — 技巧评级求解器
- `killer-generator.js` — 谜题生成器
- `variant-engine.js` — 变体引擎
- `lmd-crawler.js` — LMD 爬虫
