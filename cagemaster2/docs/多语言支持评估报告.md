## 二、UI 国际化（已完成）

### 支持语言
- **zh-CN** 简体中文（默认/母语）
- **en** 英语
- **ja** 日语
- **ko** 韩语

### 覆盖范围
- 菜单、按钮、通用提示
- 章节/关卡标题（UI 层）
- 设置页、教程页
- 游戏内 HUD 提示

### 文件位置
```
cagemaster2/utils/locales/
  ├── zh-CN.json   ← 中文（最全）
  ├── en.json      ← 英语
  ├── ja.json      ← 日语
  └── ko.json      ← 韩语
```

## 三、剧情文本（待国际化）

### 当前问题
`chapters.json` 中的所有剧情文本（introStory、preDialog、clearDialog、endingStory）均为中文硬编码，没有多语言字段。

### 建议方案

**方案 A：多语言字段内嵌（推荐）**
```json
{
  "text": "你终于来了。",
  "text_en": "You're finally here.",
  "text_ja": "やっと来たわね。",
  "text_ko": "드디어 왔네."
}
```
优点：结构简单，按需加载
缺点：JSON 体积膨胀约 3 倍

**方案 B：独立语言文件**
```
data/chapters/
  ├── chapters.zh-CN.json
  ├── chapters.en.json
  ├── chapters.ja.json
  └── chapters.ko.json
```
优点：按需加载，体积小
缺点：文件管理稍复杂

## 四、VO 配音（待国际化）

### 当前状态
- 512 条 VO 全部为中文
- 文件命名：`VO_角色_序号.wav`（如 VO_CK_01.wav）
- 存放：`assets/audio/voices/`

### 建议方案
按语言分子目录：
```
assets/audio/voices/
  ├── zh-CN/       ← 当前中文配音
  │   ├── VO_CK_01.wav
  │   └── ...
  ├── en/
  ├── ja/
  └── ko/
```

### 工作量估算
| 语言 | 台词数 | 预计时长 | 成本（AI配音） |
|------|--------|----------|----------------|
| 英语 | 512 | ~3 小时 | 低（可直接用 TTS） |
| 日语 | 512 | ~3 小时 | 低 |
| 韩语 | 512 | ~3 小时 | 低 |
