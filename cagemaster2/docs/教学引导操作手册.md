# 教学引导操作手册

## 一、系统概述

笼中数独的教学引导系统由三套机制组成：

| 系统 | 作用 | 适用场景 |
|------|------|----------|
| **GuideManager 触发器** | 48 关通用的引导系统，支持多种触发条件和引导类型 | 关卡内的提示、介绍、阶段切换 |
| **TechniqueTutorial 弹窗** | 独立弹窗式技巧教学，带分步演示 | 高级技巧入门（5个技巧） |
| **TechniqueFeedback 反馈** | 实时识别玩家使用的技巧，给出守笼人反馈 | 鼓励和强化学习 |

---

## 二、快速上手

### 2.1 如何给某一关加引导？

打开 `data/chapters.json`，找到对应关卡，在 `triggers` 数组里加一条：

```json
{
  "id": "t101_my_hint",
  "condition": "onFirstNumberFilled",
  "type": "popup_hint",
  "text": "恭喜你填对了第一个数！",
  "position": "top",
  "once": true
}
```

### 2.2 触发器的三个核心要素

每个触发器都要回答三个问题：

| 要素 | 对应字段 | 说明 |
|------|---------|------|
| **什么时候触发？** | `condition` | 触发条件（关卡开始/第一次填数/卡壳多久...） |
| **触发什么效果？** | `type` | 引导类型（气泡/聚光灯/进入阶段...） |
| **只触发一次吗？** | `once` | true = 只触发一次，false = 每次都触发 |

## 三、触发条件大全

| 条件 | 说明 | 额外参数 |
|------|------|----------|
| `onLevelStart` | 关卡开始时 | `delay`（延迟毫秒） |
| `onFirstNumberFilled` | 玩家填对第一个数时 | - |
| `onFillCountReached` | 填了 N 个数时 | `count`（目标数量） |
| `onStuckForSeconds` | 卡壳 N 秒时 | `seconds`（秒数） |
| `onConflict` | 填错数字时 | - |
| `onLevelComplete` | 通关时 | - |
| `onRowSelect` | 选中某行时 | `row`（行号） |
| `onCageSelect` | 选中某个笼子时 | `cageSize` / `cageSum` |
| `onKeyCellsFilledCorrectly` | 关键格都填对时 | `keyCells`（格子数组，不填=所有空格） |
| `onRowLastCellCorrect` | 某行最后一格填对时 | - |
| `onColLastCellCorrect` | 某列最后一格填对时 | - |
| `onBoxLastCellCorrect` | 某宫最后一格填对时 | - |

## 四、引导类型大全

### 4.1 popup_hint（气泡提示）

最常用的引导类型，小气泡飘出来，几秒后自动消失，不打断玩家操作。

```json
{
  "id": "t101_hint",
  "condition": "onStuckForSeconds",
  "seconds": 30,
  "type": "popup_hint",
  "text": "卡住了？试试看看第3行～",
  "targetR": 2,
  "targetC": 0,
  "position": "top",
  "duration": 2500,
  "once": false
}
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `text` | 提示文字 | 必填 |
| `targetR / targetC` | 指向哪个格子（气泡尾巴对着它） | 居中 |
| `position` | 气泡位置：top/bottom/left/right | top |
| `duration` | 显示多久（毫秒） | 2500 |
| `targetFromEvent` | true = 从事件数据取目标（如 onConflict 的出错格子） | false |

### 4.2 freeze_mask（冷冻遮罩/聚光灯）

全屏半透明遮罩，中间挖一个洞高亮目标区域，玩家点击后关闭。适合重要的开场介绍。

```json
{
  "id": "t101_intro",
  "condition": "onLevelStart",
  "delay": 500,
  "type": "freeze_mask",
  "targetR": 0,
  "targetC": 1,
  "targetType": "cell",
  "highlightShape": "circle",
  "text": "看这个格子！根据排除法，这里只能填 4。",
  "once": true
}
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `targetR / targetC` | 目标格子坐标（0-based） | - |
| `targetType` | 高亮类型：cell（单格）/ row（整行）/ col（整列）/ box（宫）/ cage（笼子） | cell |
| `highlightShape` | 形状：circle（圆形）/ rect（方形） | circle |
| `text` | 底部引导文字 | 必填 |

### 4.3 enter_phase（进入阶段）

切换关卡阶段（breakthrough 突破期 / finishing 收尾期），改变BGM和氛围。

```json
{
  "id": "t101_breakthrough",
  "condition": "onFillCountReached",
  "count": 6,
  "type": "enter_phase",
  "phase": "breakthrough",
  "once": true
}
```

| 参数 | 说明 |
|------|------|
| `phase` | `breakthrough`（突破期）/ `finishing`（收尾期） |

### 4.4 tutorial（交互式分步教学）

多步骤的交互式教学，会锁定格子，要求玩家按步骤操作。仅 101 关使用。

```json
{
  "id": "t101_tutorial",
  "condition": "onLevelStart",
  "type": "tutorial",
  "tutorialId": "tutorial_intro_101",
  "once": true
}
```

### 4.5 badge_award / calc_panel（预留）

这两个类型目前只有日志输出，暂无实际UI效果，后续会实现。

## 五、目标定位说明

所有带目标的引导（freeze_mask、popup_hint）都支持以下目标类型：

| targetType | 说明 | 需要的参数 |
|------------|------|-----------|
| `cell` | 单个格子 | targetR, targetC |
| `row` | 整行 | targetR |
| `col` | 整列 | targetC |
| `box` | 整个宫 | targetR, targetC（任意一个宫内的格子坐标即可） |
| `cage` | 整个笼子 | highlightCage 或 targetFromEvent |
| `full` | 全屏无高亮 | - |

## 六、如何测试引导？

### 6.1 快速测试某一关

```
http://localhost:8080/guide.html?levelId=101&story=1
```

### 6.2 触发特定条件

| 条件 | 测试方法 |
|------|----------|
| onLevelStart | 刷新页面就行 |
| onFirstNumberFilled | 填一个数 |
| onFillCountReached | 填够 N 个数 |
| onStuckForSeconds | 什么都不做，等 N 秒 |
| onConflict | 故意填错一个数字 |
| onKeyCellsFilledCorrectly | 把所有空格都填上 |

### 6.3 重置引导记录

引导如果设了 `once: true`，触发过一次就不会再触发了。测试时：

1. 设置里点「重置剧情」→ 会清除所有引导触发记录
2. 或者直接加 `?story=1` 参数 → 强制重播所有引导

## 七、常见问题

### Q: 为什么我的引导不触发？

1. 检查 `condition` 拼写对不对
2. 检查 `once: true` 的话，是不是已经触发过了（用 `?story=1` 重置）
3. 打开浏览器控制台（F12），看有没有 `🔥 [GuideManager] 触发:` 的日志

### Q: 聚光灯位置不对？

1. 检查 `targetR / targetC` 是不是 0-based（从0开始数，不是从1）
2. 检查 `targetType` 对不对（整行就用 row，整列就用 col）
3. 如果是异形布局，可能 padding 不对——确认 renderer 的 paddingLeft/paddingTop

### Q: 气泡没有指向格子？

检查有没有设置 `targetR / targetC`，没设置的话气泡会居中显示。

### Q: 怎么让气泡指向出错的格子？

设置 `"targetFromEvent": true`，onConflict 这类带事件数据的条件会自动把目标传过去。
