# FreezeMask 聚光灯对齐问题修复记录

## 问题描述

1-1 教学引导的 freeze mask 聚光灯与需要聚焦的格子没有完全对齐，聚光灯位置偏移。

## 问题定位

### 涉及文件
- `tutorial/guide-manager.js` — 引导管理器，包含 FreezeMask 和 PopupHint 两个组件

### 根本原因

**原因1：padding 计算方式不匹配**

Renderer（渲染器）使用独立的四边 padding：
```javascript
// renderer.js
this._paddingTop = 12;
this._paddingBottom = 12;
this._paddingLeft = 12;
this._paddingRight = 12;

// 绘制时使用：
ctx.translate(padL, padT);  // padL = this.paddingLeft, padT = this.paddingTop
```

但引导系统（FreezeMask / PopupHint）只用了一个统一的 `padding` 值：
```javascript
// 修复前 guide-manager.js
const cellX = padding + targetC * cellSize;  // 假设左右 padding 相同
const cellY = padding + targetR * cellSize;  // 假设上下 padding 相同
```

当 `paddingLeft ≠ paddingTop` 时（例如某些主题或布局下，上下边距和左右边距不同），聚光灯位置就会偏移。

**原因2：圆形聚光灯大小计算过小**

```javascript
// 修复前
if (highlightShape === 'circle') {
  const size = Math.max(width, height) * 0.7;  // 只有目标区域的 70%
}
```

0.7 倍的缩放导致圆形聚光灯比目标格子小，视觉上"套不准"。

## 修复方案

### 修复1：支持独立的 paddingLeft / paddingTop

修改 `FreezeMask.show()` 和 `PopupHint.show()` 方法，新增两个参数：
- `paddingLeft` — 左边距（优先使用，默认 null 则回退到 padding）
- `paddingTop` — 上边距（优先使用，默认 null 则回退到 padding）

**修改位置：**

1. `FreezeMask.show()` — 新增参数 + 传递给 `_positionSpotlight()`
2. `FreezeMask._positionSpotlight()` — 使用 `padL` 和 `padT` 分别计算 X/Y 偏移
3. `PopupHint.show()` — 新增参数 + 传递给 `_positionBubble()`
4. `PopupHint._positionBubble()` — 使用 `padL` 和 `padT` 分别计算 X/Y 偏移
5. `GuideManager._showFreezeMask()` — 从 renderer 获取 `paddingLeft/paddingTop` 并传入
6. `GuideManager._showPopupHint()` — 从 renderer 获取 `paddingLeft/paddingTop` 并传入

### 修复2：调整圆形聚光灯大小

```javascript
// 修复后
if (highlightShape === 'circle') {
  const size = Math.max(width, height);  // 100%，完整覆盖目标区域
}
```

同时单格聚光灯的宽高从 `w * 0.9` 调整为 `w * 1.1`，略大于格子，确保完整覆盖。

## 关键代码变更

### 1. FreezeMask._positionSpotlight()

**修复前：**
```javascript
const boardSize = (rect.width - padding * 2) / cellSize;
// ...
const cellX = padding + targetC * cellSize;
const cellY = padding + targetR * cellSize;
// ...
width = w * 0.9;
height = h * 0.9;
// ...
const size = Math.max(width, height) * 0.7;
```

**修复后：**
```javascript
const padL = paddingLeft !== undefined ? paddingLeft : 12;
const padT = paddingTop !== undefined ? paddingTop : 12;
const boardSize = (rect.width - padL * 2) / cellSize;
// ...
const cellX = padL + targetC * cellSize;
const cellY = padT + targetR * cellSize;
// ...
width = w * 1.1;   // 略大于格子，确保完整覆盖
height = h * 1.1;
// ...
const size = Math.max(width, height);  // 100%，不再缩小
```

### 2. PopupHint._positionBubble()

**修复前：**
```javascript
const cellCenterX = rect.left + padding + (targetC + 0.5) * cellSize;
const cellCenterY = rect.top + padding + (targetR + 0.5) * cellSize;
```

**修复后：**
```javascript
const padL = paddingLeft !== undefined ? paddingLeft : 12;
const padT = paddingTop !== undefined ? paddingTop : 12;
const cellCenterX = rect.left + padL + (targetC + 0.5) * cellSize;
const cellCenterY = rect.top + padT + (targetR + 0.5) * cellSize;
```

## 向后兼容性

- 保留了 `padding` 参数作为默认值，旧代码不传 `paddingLeft/paddingTop` 也能正常工作
- 当 `paddingLeft = null` 时自动回退到 `padding` 值
- 所有 targetType（cell/cage/row/box）都已同步修复

## 扩展：如何添加新的引导步骤

在 `data/chapters.json` 对应关卡的 `triggers` 数组中添加：

```json
{
  "id": "t101_highlight",
  "condition": "onLevelStart",
  "type": "freeze_mask",
  "targetR": 0,
  "targetC": 1,
  "targetType": "cell",
  "highlightShape": "circle",
  "text": "看这个格子！",
  "delay": 500,
  "once": true
}
```

**参数说明：**
- `targetR / targetC` — 目标格子坐标（0-based）
- `targetType` — `cell`（单格）/ `cage`（笼子）/ `row`（整行）/ `box`（宫）/ `full`（全屏无高亮）
- `highlightShape` — `circle`（圆形）/ `rect`（方形）
- `text` — 引导文字
- `delay` — 延迟显示（毫秒）
- `once` — 是否只触发一次
