# 游戏启动与测试指南

## 一、本地启动服务

### 方式一：Python HTTP 服务器（推荐）

```bash
cd d:\killersudoku\cagemaster2
python -m http.server 8080
```

启动后访问：**http://localhost:8080/**

### 方式二：Node.js http-server

```bash
cd d:\killersudoku\cagemaster2
npx http-server -p 8080 -c-1
```

### 方式三：VSCode Live Server 插件

安装 Live Server 插件后，右键 `index.html` → "Open with Live Server"

---

## 二、手机上测试

### 前提条件
1. 手机和电脑连接 **同一个 Wi-Fi**
2. 电脑防火墙允许 8080 端口入站

### 步骤

**1. 查看电脑局域网 IP**

Windows:
```bash
ipconfig
```
找到 "IPv4 地址"，通常形如 `192.168.x.x` 或 `10.x.x.x`

**2. 启动服务（绑定 0.0.0.0）**

```bash
cd d:\killersudoku\cagemaster2
python -m http.server 8080 --bind 0.0.0.0
```

**3. 手机浏览器访问**

```
http://你的电脑IP:8080/
```

例如：`http://192.168.1.100:8080/`

### 端口说明

| 端口 | 用途 |
|------|------|
| 8080 | 默认开发端口 |
| 3000 | 备用端口 |
| 5500 | VSCode Live Server 默认端口 |

## 三、常用调试参数

在 URL 后添加参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| `?story=1` | 强制重播剧情 | `guide.html?levelId=101&story=1` |
| `?levelId=XXX` | 直接进入指定关卡 | `guide.html?levelId=205` |
| `?route=2` | 切换周目路线 | `chapters.html?route=2` |
| `?debug=1` | 开启调试模式 | `guide.html?levelId=101&debug=1` |

## 五、常见问题

### Q: 手机访问不了？
1. 确认手机和电脑在同一 Wi-Fi
2. 确认电脑 IP 地址正确
3. 检查 Windows 防火墙是否放行
4. 试试关闭 VPN/代理

### Q: 剧情不播放？
加 `?story=1` 参数强制重播，或在设置里点"重置剧情"

### Q: 背景图不显示？
检查浏览器控制台（F12）的 Network 面板，看图片是否 404
