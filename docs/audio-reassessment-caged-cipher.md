### 1.2 关键结论
- **VO 生产≈重启动**：旧 1241 条里可保留的仅 沈墨/薇拉/旁白 三类（约 300+ 条），其余需按新剧本重新生成。
- **多语策略**：主语音 zh-CN 必做；en/ja/ko 三语剧本已存在（`i18n/*.txt` + `locale/*/levels.json`），若做本地化 VO，则每角色 ×4 语。IndexTTS 2.5 支持中/英/日零样本克隆（含情感迁移），**JA/KO 建议用 2.5 而非 2**（见下）。
- **生成工具建议**：新角色声线（尤其苏晚 SW）用 **IndexTTS 2.5** 建声纹——理由：① 多语零样本（JA/KO 本地化直接可用）；② 情感解耦+`emo_alpha` 强度微调适合谍战演出；③ 推理 2.28× 快、8G 显存可跑；④ 官方称中文克隆保真度"可比"2.0（盲听 A/B 通过即可）。商用需走 bilibili 授权（indexspeech@bilibili.com）。
- **一致性校验**：新生成的 沈墨/薇拉 须与存量 `VO_SM_*`/`VO_ayan_*` 抽 3–5 条盲听，确认音色不漂移。

### 1.3 VO 文件命名（沿用既有规范，新增前缀）
```
voice/<CHAR>/VO_<CHAR>_<####>.mp3
新增前缀：SW_ / ZT_ / PH_ / SD_ / IT_ / LS_ / FQ_
```
登记入口：`assets/audio/voice/voice_index.json` 新增对应条目。

## 四、★ 拆弹 / 解码类任务专属音乐（用户特别要求）

> 新剧本**无字面"拆弹"**，但有两类高频高压交互任务，功能上完全等价于"拆弹/解码"，必须配**专属 BGM**（而非仅 SFX）。下面给出映射与音乐设计。

### 4.1 解码型（Decoding / 破译）—— `bgm_decode`
**覆盖节点**（剧本实证）：
- 205 旧稿破译（`### 205 旧稿破译` / en "Level 5 · Deciphering the Old Drafts"）
- 404 破译照片隐秘线索（`404房 · 破译照片隐秘线索`）
- 405 解匿名信（`Decode anonymous note`）
- 547–548 收暗号信并辨识格式（`Receive the anonymous cipher letter`）
- 全部【交互·综合解谜】节点（261 / 554 / 888）

**音乐设计**：
- 性格：精密、克制、略带悬疑的"解开"动机；以拨弦/钢琴单音 + 低频脉冲铺底，暗示"逻辑推演"。
- 结构：可无缝循环；建议 90–100 BPM。
- 成功反馈：接 `eureka.mp3`（灵感闪现 stinger），作为"破译成功"统一收尾。
- 接入：在 `BGM_BPM_MAP` 增 `bgm_decode`（tension≈0.45，固定）。

### 4.2 拆弹型（Defusal / 倒计时）—— `bgm_defuse`
**覆盖节点**（剧本实证，功能=定时拆弹的高压节拍）：
- 电章 climax：501–509 发报机·三组电文三秒一段间隔发出·**测向车逼近**（`chapters.5` 描述"测向车的逼近"；1273 "无线电监测车全员开机，织密全城电波封锁网"）
- 全局危机：936 "太平洋战争倒计时走到最后时刻；地面搜捕已经逼近沈墨居所"；945 "所有人的时间，都在极速倒计时中逼近终点"
- 珍珠港消息：1273–1274 最终倒计时 / 冷雨逼近
- 终局"险爆未爆"：en 7905 "No explosion. No revelation."（用 `bgm_defuse_resolve` 安静落定）

**音乐设计**：
- 性格：**心跳/低频脉冲驱动 + tick-tock 节奏**，张力可递增循环；铜管/弦乐不进，留"屏息"空间。
- 结构：100–112 BPM；建议做 2 段（紧张段 `bgm_defuse` + 解除段 `bgm_defuse_resolve` 安静尾）。
- 与 SFX 协同：`direction_finder_near`（测向车逼近）+ `telegraph_key`（三秒电文）叠在 `bgm_defuse` 上，形成"边发报边躲侦测"的复合高压。
- 接入：在 `BGM_BPM_MAP` 增 `bgm_defuse`（tension≈0.8，可随 Phase 2 连续张力参数联动）。

### 4.3 为什么必须"专属 BGM"而非仅 SFX
拆弹/解码是**持续数十秒的交互态**，不是一次性触发音。纯 SFX 无法承载"时间压力→成功/失败"的情绪弧；需要一条可循环的 tension bed 让玩家**持续感到倒计时**。这正是 Game Audio 的"adaptive music / tension parameter"原则——`bgm_decode`/`bgm_defuse` 即两条 tension 态音乐，与章节 BGM 平级。
