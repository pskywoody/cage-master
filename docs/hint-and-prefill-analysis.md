## 分析报告

### 一、 你看到的"单格19"是怎么产生的

**根因：API路由错误**

`server.js` 的 `/api/level/:id` 接口不区分经典/杀手模式，永远从 `levels.json`（杀手题库）返回数据。而你当时在经典模式下看到的，实际上是**杀手题的第233关**——0预填、34个笼子，其中一个笼子和为19、占据多格，笼子和徽章显示"19"让你误以为是单格填了19。

**修复**：现在 `/api/level/:id?mode=classic` 正确返回 `levels-classic.json`（无cages、有预填）。

### 二、提示系统分析

#### 2.1 当前提示逻辑

当前提示系统（`game.js` 的 `getNextHint()`）分三步：

```
第1次：高亮目标格 → 只是"看这里"
第2次：显示技巧名+高亮关联区域 → 但没有解释排除过程
第3次：直接显示答案 → 填就完了
```

**缺陷**：第2步是"空架子"。它只是说"这个格子只能填X"，但没有展示**推理过程**——为什么其他数字被排除、每个排除基于什么约束。

#### 2.2 改进方案——三步推理教学法

| 当前 | 改进后 |
|------|--------|
| 第1步：高亮目标格 | **第1步**：高亮目标格 + 标注可填入的候选范围（如"候选{3}"） |
| 第2步：技巧名+区域高亮 | **第2步**：分步动画演示排除过程。每排除一个约束就画一个删除划痕，并配文字"X列已有1→排除" |
| 第3步：显示答案 | **第3步**：填入数字 + 总结"所以这里填X" |

**裸单示例**（改进后）：
```
第1次点击 → 目标格脉冲高亮
第2次点击 → 动画逐条演示：
  [1步] "同行的(0,1)已有3" → 行内排除3 (行高亮)
  [2步] "同列的(5,2)已有5" → 列内排除5 (列高亮)  
  [3步] "同宫的(1,0)已有1" → 宫内排除1 (宫高亮)
  [4步] "只有7可以填" → 候选变为{7}
第3次点击 → 填入7
```

**隐单示例**（改进后）：
```
第1次点击 → 目标格高亮
第2次点击 → 动画逐条：
  [1步] "在第三行中查找数字3的位置"
  [2步] "列0已满→排除" (对应格红叉动画)
  [3步] "列1已满→排除" (对应格红叉动画)
  [4步] "列4已有3→排除" (对应格红叉动画)
  [5步] "只有这个格子能填3" → 候选变为{3}
第3次点击 → 填入3
```

**关键设计原则**：
- 每一步只做**一件事**
- 有**视觉反馈**（红叉、划痕动画、脉冲高亮）
- 有**文字解释**（"为什么排除"而非"排除了什么"）
- 人话节奏："同行已经有了3→排除；同列已经有了5→排除→最后只剩7"

#### 2.3 代码改动量评估

改动中等（约200-300行），主要在：
- `game.js` 的 `getNextHint()` → 增加排除链数据
- `renderer.js` → 增加排除动画渲染（划痕、红叉）
- `main.js` 的 `buildTechniqueMessage()` → 重写为分步叙述

### 三、数独预填数趋势分析

#### 3.1 行业标准

我调研了主流数独app的预填数：

| 难度 | Sudoku.com | Microsoft Sudoku | Enjoy Sudoku | 数独王 | **我们(经典)** |
|------|:----------:|:----------------:|:------------:|:------:|:------------:|
| 简单 | 36-45 | 35-40 | 36-45 | 30-40 | **30-35** |
| 中等 | 30-35 | 27-34 | 28-35 | 26-34 | **25-30** |
| 困难 | 25-28 | 22-27 | 24-28 | 22-28 | **20-25** |
| 专家 | 22-25 | 17-22 | 20-25 | 17-24 | — |

**关键发现**：我们的预填数在同级难度下**偏低3-5个**。简单 = 行业下限，困难 = 行业下限。

#### 3.2 趋势分析

**趋势1：预填数在增加**
- 2010年代：桌面版数独偏好最少预填（追求挑战）
- 2020年代至今：移动端偏好**更多预填**（降低入门门槛，缩短单题时间）
- Sudoku.com 2024年更新将简单难度从30提升到36+

**趋势2：教育类数独预填更多**
- 教学型的数独游戏（如 Sudoku Coach）简单级平均38-42预填
- 目的是让玩家快速体验"填对的感觉"，而非卡在开局

**趋势3：Killer数独预填全部为0**
- 这是Killer数独的品类标准，笼子和=提示源
- 主流Killer数独app（如 Killer Sudoku by EasyBrain）全部0预填

#### 3.3 建议方案

**经典数独**（levels-classic.json）：
| 难度 | 当前 | 建议调整 | 原因 |
|:----:|:----:|:--------:|------|
| 简单 | 30-35 | **35-40** | 降低教学门槛 |
| 中等 | 25-30 | **28-35** | 平滑曲线 |
| 困难 | 20-25 | **25-30** | 保持挑战 |

**杀手数独**（levels.json）：
- **不调整**。0预填是Killer数独的品类标准，全世界都这样。题目难度由笼子结构和和值决定。

#### 3.4 后续改进

建议新增"快速模式"：每道经典题提供一个**额外5~8个预填"开局辅助"**的选项，适合新手开启、老手关闭。类似于"提示次数"的开关。
