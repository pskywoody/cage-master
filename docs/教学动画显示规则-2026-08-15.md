# 教学动画显示规则（统一规范）

> 目的：让教学演示与提示的动画表达有一致的、可复用的规则，避免逐关手写不同的"亮一下/说一句"。
> 当前版本：0.1（2026-08-15）
> 适用：`core/lesson-player.js`（教学）与 `renderer/hint-adapter.js` + `expert/hint-system.js`（提示）

## 一、核心原则

1. **说的格子就一定亮，讲的数字就用笔记呈现。** 文案提到哪个格/哪些格，就要把它们高亮；文案说"某格/某行/列/宫有数字 X/Y/Z"，就应把对应的来源格亮出来，并把数字用"笔记"小字显示在这些格上。
2. **先亮区域，再亮格，再亮数字，再排除。** 讲解顺序固定为：定位区域（宫/行/列/笼）→ 亮出相关格子 → 弹出候选/来源数字笔记 → 被排除的格子打红叉或划线 → 目标格揭晓。
3. **信息是累加的，不是互相覆盖的。** 同一步骤内已经点亮的元素保持到"这一步讲解结束"再统一熄灭（填对/进入下一阶段时清）。
4. **同一技巧用同一套动画，四语只换文案不换结构。** 301 的行区块、302 的列区块、303 的宫区块应当是同一种"区块排除"动画模板，只是方向参数不同。

## 二、统一动作词汇（Demo/Hint 共用）

在现有 `highlightRow/Col/Box/Cage/Cell`、`focusCell`、`spotlight` 基础上新增/明确：

| 动作 | 含义 | 视觉 |
|---|---|---|
| `highlightCells` | 一次高亮多个格子 | 多格同屏高亮 |
| `highlightRegion` | 高亮宫/行/列/笼（可复用 highlightBox/Row/Col/Cage） | 区域半透明铺底 |
| `showNote` | 在指定格显示候选/来源数字 | 格内左上出现小数字笔记 |
| `showNotes` | 多个格同时显示同一数字笔记 | 多格左上同数字 |
| `strikeNote` | 把某格某个笔记打红叉/划线 | 笔记上划一道 |
| `concludeCell` | 目标格确定 | 目标格脉冲 + 数字落定 |

## 三、按技巧的动画模板

### 3.1 区块排除（pointing/claiming）

行区块（301）与列区块（302）同一模板：

1. `highlightRegion(box)`：亮来源宫，讲"看这个宫"。
2. `showNote` 到宫内附件来源格：亮起"宫外同方向已存在的数字来源格"（如 e4/h9 这类"已有 4/9 的格"）。
3. `highlightCells + showNotes`：把宫内被限制的那一行的待排除格（如 g6/h6）一起亮并弹出笔记 `N`。
4. `strikeNote`：这些待排除格上的 `N` 画红叉（表示"这里不能是 N"）。
5. `highlightCells`：把剩下的可行格（如 g5/h5）一起亮 → 揭示区块方向。
6. `concludeCell`：目标格填数。

### 3.2 裸单（nakedSingle）/ 隐曜（hiddenSingle）

1. `highlightCells`：目标格。
2. `showNotes`：目标格先亮出全部候选。
3. 来源高亮 + `strikeNote`：逐个排除候选（来源数字用笔记，被排除的候选打叉）。
4. `concludeCell`：只剩一个，揭晓。

### 3.3 星衡法则（rule45）

沿用现有账本求和动画：`pulseCageSum` 逐笼求和 → 亮行/列/宫 → `concludeCell`。

### 3.4 并蒂锁/双曜/三子法/二连纵横阵/三才游鱼阵

1. `highlightCells` 锁定格组。
2. `showNotes` 锁定数字。
3. `strikeNote` 从其他格排除这些数字。
4. `concludeCell`。

## 四、气泡与 Q 版人物布局

1. 教学气泡锚定 chibi 右侧、棋盘上方，不遮挡盘面。
2. 气泡固定宽度，字体略小；格子标识与数字用不同颜色。
3. 打字机光标跟在字末，不另占行。
4. chibi 位于棋盘上缘，只让手轻微搭在盘沿，不遮挡 a 行。

## 五、落地路径

1. 先补渲染能力：`showNote/showNotes/strikeNote/concludeCell` 与气泡彩色 token。
2. 再按模板重排 301/302/303 三关作为试点。
3. 逐关核验规则，批量修正其余教学关与提示话术。
