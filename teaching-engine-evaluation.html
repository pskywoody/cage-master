GuideManager 引导管理器
★★★★★ 9.5/10

核心组件

  • FreezeMask: 全屏冷冻遮罩 + 挖空高亮 + 引导文字 + 动画
  • PopupHint: 气泡提示 + 尾巴指向 + 自动淡出 + 边界检测
  • GuideManager: 触发器引擎 + 条件匹配 + 去重 + 持久化

触发器类型

onLevelStart onFirstNumberFilled onFillCountReached onStuckForSeconds onConflict onCageSelect onRowSelect onBoxFillProgress onRowFillProgress onLevelComplete onBoxLastCellCorrect onRowLastCellCorrect onColLastCellCorrect onBoxLastCellWrong onRowLastCellWrong onColLastCellWrong freeze_mask popup_hint enter_phase calc_panel (预留) badge_award (预留)

亮点

  • once去重: 同一触发器在同关卡仅执行一次，避免重复打扰
  • 延迟触发: 支持 delay 配置毫秒数，灵活编排引导时序
  • 标准化配置: trigger 配置格式统一，便于关卡设计师快速添加引导
  • localStorage 持久化: 已触发记录持久保存，跨 session 不重复
  • 边界检测: PopupHint 自动检测屏幕边缘并调整气泡位置

guide.js 三阶段教学框架
★★★★★ 9.0/10

三阶段模型

opening breakthrough finishing complete

阶段切换检测

  • 自动: opening→breakthrough（填 ≥35% + 无裸单/隐单）
  • 自动: breakthrough→finishing（破局后填 ≥2格 + 连锁裸单出现, 或空格 <15%）
  • 脚本: 通过 trigger enter_phase 强制切换
  • 手动: 可调用 enterBreakthrough() / enterFinishing()

阶段特效

  • 暗化遮罩 + 阶段指示器（3秒显示）
  • 逆转裁判式金色闪光动画
  • 撒花粒子效果（庆祝氛围）
  • BGM 切换（阶段性音乐变化）

残局教学关

  • 锁定非关键格，仅关键格可交互
  • 关键格进度追踪（完成度可视化）
  • 防猜机制: _breakthroughWrongCount 连续错误计数

三层提示系统

  • L1 目标格位置 → 绿色高亮
  • L2 技巧名称 + 关联区域 → 紫色高亮（关键格）+ 金色区域
  • L3 答案/Tutorial → 基础技巧显示数字，高级技巧启动 TechniqueTutorial

内部状态: hintStep(0→1→2→3), currentHint, _isHintShowing 防冲突

TechniqueTutorial 高级技巧可视化教程
★★★★★ 9.5/10

已实现教程

Naked Pair 显性数对 Hidden Pair 隐性数对 Triple 三链数 X-Wing Swordfish 剑鱼

设计特点

  • 极简盘面: 仅保留关键格子，其余全部填满（零干扰）
  • 分步演示: 每步只讲一件事，逐步叠加理解
  • 丰富视觉元素: 大圆圈、大箭头、行/列/宫荧光带、红叉标记、emoji 标记、脉冲动画
  • 颜色编码: 关键格（绿）、数对（金）、排除格（红）、结果（青）、辅助（蓝）
  • 角色对话: 守笼人 / 阿岩口语化教学
  • 进度条: 步骤指示器 + 上一步/下一步/我学会了 按钮
  • Canvas 渲染: 9x9 盘面，支持候选数绘制、排除标记、连线、指向箭头
  • i18n 合并: 教程文本支持多语言覆盖

TechniqueDemo 技巧演示系统
★★★★☆ 7.0/10

功能概述

  • 在游戏 Canvas 上方叠加透明图层，绘制教学标注
  • 支持多种高亮类型、连线、箭头、标记（emoji / redx / circle / finger / label 等）
  • ResizeObserver 自适应

局限

  • 覆盖层不是交互式的，仅作为标注图层使用
  • 功能基础，适合简单标注和提示

TechniqueFeedback 技巧识别反馈系统
★★★★★ 8.5/10

检测技巧顺序

nakedSingle hiddenSingle rule45（45法则） nakedPair

检测原理

填数前状态快照对比 → 识别玩家使用的技巧

反馈调度

  • 全局冷却 5 秒（任意 feedback 间最小间隔）
  • 同类冷却 同一技巧 30 秒内不重复
  • 首次例外 首次使用某技巧强制触发反馈
  • 连击检测 连续 3 次同一高级技巧触发连击台词

反馈类型

first 首次使用  |  normal 常规  |  combo 连击

反馈输出

StoryEngine 环境台词 → ComedySystem 气泡降级

i18n 台词: 从 i18n 读取守笼人台词

教学引擎的三个最强点

#3 STRONGEST

手把手可视化教学

TechniqueTutorial 以极简盘面 + 分步演示 + 角色对话 + 丰富视觉元素，实现高级技巧的零门槛教学
